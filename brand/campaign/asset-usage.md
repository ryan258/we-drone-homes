# Campaign placement and export notes

Use the asset built for the placement. Keep the illustrated property, fiction label, and next action together. The artwork uses embedded photos, editable type, and the outlined identity master. Install or substitute the specified system typefaces in your design editor when adjusting text; reflow and recheck after a substitution.

Use sRGB for digital exports. Keep the original proportions; size the image to fit if an embed uses different dimensions. The landscape preview has a secondary “Fictional property” label inside its central square crop. Use the square creative for intentional square placement so the main message survives. Open each target preview once before sharing, because crops and overlay controls vary. For print, use the SVG as the placement master, allow the printer to specify the production color profile, and request a proof before any print run. The one-sheet is a margin-safe office-print layout.

Use the suggested alt text in the [copy bank](COPY-AND-LAUNCH.html) and revise it if you change the art or crop. Treat the CTA in the artwork as printed copy; use the surrounding post or page for the actual link. Credit the stills as fictional illustrations; the [art notes](../art/README.md) identify the source for each image.
